## 실험실 장면

- **🚗 달려 보기** — 속력을 정하고 ▶. 1초마다 잔상이 찍히고 **간격이 일정**함을 본다.
- **🏁 누가 더 빠를까** — A·B 의 속력을 바꿔 **그래프가 가파를수록 빠르다**는 것을 본다.
- **🔀 등속이 아닌 운동** — 등속 · 점점 빨라짐 · 점점 느려짐. 셋 다 **10초 뒤 50 m**에 닿지만 그래프 모양이 다르다.
- **🏆 미션 6개** — 예측 → 확인 → 이유 공개.

## 이 앱의 결론

1. 등속 운동은 **1초마다 이동한 거리가 같다.**
2. **시간-이동 거리 그래프**는 원점을 지나는 직선이고 **기울기가 곧 속력**이다.
3. **시간-속력 그래프**는 시간축에 나란한 **수평선**이다.
